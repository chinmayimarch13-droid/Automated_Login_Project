
# Automated Login Testing Project

This project demonstrates **manual and automation testing** using Selenium with Python.

## Demo Website
[Login Page](https://the-internet.herokuapp.com/login)

## Goal
- Test valid login
- Test invalid login
- Print results in console

## Files
- `login_test.py` : Selenium Python code
- `login_test_notes.txt` : Project notes and steps
- `README.md` : Project description

## Locators Used
- ID
- CLASS_NAME

## How to Run
1. Open Python file in PyCharm
2. Install Selenium: `pip install selenium`
3. Run `login_test.py`
